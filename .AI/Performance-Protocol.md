# Performance Protocol

## Mission

Performance is a feature.

All systems must remain:
- responsive
- efficient
- lightweight

---

# Frontend Rules

Prevent:
- unnecessary renders
- oversized bundles
- duplicate requests

---

# Backend Rules

Prevent:
- N+1 queries
- blocking operations
- unnecessary database calls

---

# Optimization Philosophy

Optimize:
- measured bottlenecks
- verified hotspots

Avoid premature optimization.
