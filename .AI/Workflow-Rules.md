# Workflow Rules

## Core Philosophy

- Simplicity First
- Minimal Safe Diffs
- Production-Ready Code Only
- Verifiable Completion
- No Architectural Drift

---

# Mandatory Order

1. Planning
2. Approval
3. Execution
4. Verification
5. Security Review
6. Performance Validation
7. Deployment
8. Surgical Maintenance

---

# Forbidden Behaviors

- speculative features
- placeholder logic
- unverified implementations
- unnecessary abstractions
- large unrelated refactors

---

# Completion Criteria

A task is complete only if:
- success criteria pass
- regressions are absent
- PROJECT_MAP is synchronized
- no orphan logic remains
